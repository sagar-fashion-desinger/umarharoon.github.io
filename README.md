# Sagar Fashion Designer

Professional static website starter for Sagar Fashion Designer, Peshawar, Pakistan.

## Included
- Responsive luxury fashion layout
- Collections: Bridal Wear, Formal Wear, Maxis, Formal Shirts, Ready-Made, Customized Designs
- WhatsApp order buttons using +92 318 5484406
- About, Gallery and Contact sections
- Local sample SVG visuals that can be replaced with real clothing photos
- Placeholder brand mark until the real logo is added

## Replace the sample visuals
Put your real photos in `assets/` and update the `<img src="...">` paths in `index.html`.

## Publish for free
